# Shell `cns` (Module Federation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a new `cns-shell` Angular app with a single sidebar menu (Home/Chamados/Agenda/OS) and a decorative calendar on Home, composing the 3 existing modules (pouichamados, cnsaagenda, pouios) as Module Federation remotes — without touching the original projects.

**Architecture:** `@angular-architects/native-federation-v4` (the Angular-21-compatible build of Native Federation, esbuild-based, no Webpack). Copies of the 3 existing apps live inside a new `MVC/cns-super/` folder and become federation **remotes**, each exposing `./Routes`. A 4th new project, `MVC/cns-super/cns-shell/`, is the federation **host**: it owns the menu, the Home/calendar page, and lazy-loads each remote's routes via `loadRemoteModule`. The original `MVC/pouichamados`, `MVC/cnsaagenda`, `MVC/pouios` folders are never modified.

**Tech Stack:** Angular 21.2 (esbuild `@angular/build:application` builder), `@po-ui/ng-components`/`@po-ui/ng-templates`/`@po-ui/style`/`@totvs/po-theme` (aligned to `^21.26.0`), `@angular-architects/native-federation-v4`.

## Global Constraints

- Never modify `MVC/pouichamados`, `MVC/cnsaagenda`, or `MVC/pouios` (the originals). All work happens in copies under `MVC/cns-super/`.
- `@po-ui/ng-components`, `@po-ui/ng-templates`, `@po-ui/style`, `@totvs/po-theme` must be pinned to the same version (`^21.26.0`) across every project inside `cns-super` (host + 3 remotes) — Native Federation's `shareAll({ singleton: true, strictVersion: true })` throws at runtime if shared deps mismatch.
- No cross-module shared state and no automated tests in this plan — per the approved spec (`docs/superpowers/specs/2026-08-03-cns-shell-design.md`), verification is manual (dev servers + browser click-through).
- Dev ports: `cns-shell` host = 4200, `pouichamados` remote = 4201, `cnsaagenda` remote = 4202, `pouios` remote = 4203.
